Flux des données : chaque page, sa requête SQL

Infirmière
POST /predict
INSERT INTO predictions ... RETURNING id
Écrit la prédiction et récupère l'ID de suivi.
Médecin · recherche
GET /patient/{id}
SELECT * FROM predictions WHERE id = :id
Lit la prédiction pour remplir les champs.
Médecin · confirme
POST /confirmer
INSERT INTO diagnostics_confirmes (prediction_id, malade)
Écrit la vérité, reliée par l'ID.
Monitoring
GET /monitoring
SELECT ... JOIN diagnostics_confirmes ON prediction_id = id
Relie prédit et réel, calcule la précision.

GitHub

Render
